---
title: Agentflow router
description: Select the smallest useful set of engineering skills without forcing a fixed pipeline.
---

Use Agentflow when the next engineering decision is unclear, multiple disciplines are involved, or you explicitly want an SDLC routing audit.

**Do not use** the router to add overhead to a deterministic typo fix or to override an explicitly selected specialist skill.

## Example

```text
Use agentflow to review the authentication flow.
Route only the unresolved product, system, implementation, security, and verification questions.
```

The router consults canonical specialist instructions when installed and accessible. It does not install other skills, overwrite project rules, or guarantee automatic activation in every AI agent.

Read the [install guide](/start/install/) to install globally or in one project.

**Canonical runtime reference:** [agentflow](/reference/agentflow/)
