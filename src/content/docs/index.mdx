## Mental model

<div class="flow">

```text
task
  ↓
what decision is actually unclear?
  ↓
smallest useful skill
  ↓
resolve that decision
  ↓
another non-trivial decision appears?
  ├─ no  → continue the work directly
  └─ yes → hand off to the relevant skill
```

</div>

A skill is **not** a mandatory phase. A small deterministic bug may need no specialist skill. A full-stack feature may use several skills, but each one owns a distinct decision.
