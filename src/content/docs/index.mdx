## Start with the decision, not the skill name

Every engineering task contains decisions. Some need product clarity, some need architecture, a test strategy, or a code review. Invoking every skill for every task adds unnecessary work.

**Agentflow helps coding agents choose the smallest relevant set of skills for the decision in front of them.** If the solution is already clear, skip the ceremony.

```text
Your task
   ↓
What decision is unresolved?
   ├─ none → act directly
   └─ yes  → select the relevant specialist
                 ↓
           apply its guidance
                 ↓
             verify results
```

## One router. Ten specialists.

The `agentflow` skill is the entry point when you need help deciding which engineering lens to use. Each specialist owns a distinct problem: product behavior, architecture, interface, implementation, verification, security, production, code review, delegation, or visual graph output.

## Portable by design

Agentflow is a set of versioned `SKILL.md` instructions, not a standalone AI model, hosted orchestration platform, or another package manager. Install selected skills through the [skills ecosystem](/start/distribution/), or use the [native Claude Code and Codex plugins](/start/native-plugins/) where available.

**Install the router and specialists together** if you want the router to consult their full instructions. Installing the router alone does not install the ten specialists. Activation and invocation syntax depend on your coding agent.
