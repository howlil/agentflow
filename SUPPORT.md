# Support

For Agentflow installation, skill routing, packaging or usage problems, use the repository's [GitHub Issues](https://github.com/howlil/agentflow/issues). GitHub Discussions is not currently offered as an official support channel.

Before posting, check [README](README.md), the [installation guide](src/content/docs/start/install.md), and [existing issues](https://github.com/howlil/agentflow/issues).

For an actionable report, include the expected and observed behavior, your coding host, installation method (portable CLI, native plugin, or ChatGPT Web), relevant versions, reproduction steps, and **sanitized** logs. Indicate whether a result was observed, proposed, or not tested.

For security vulnerabilities or sensitive information, **do not file a public technical report**; follow [SECURITY.md](SECURITY.md). For contributions, see [CONTRIBUTING.md](CONTRIBUTING.md).

Support is community-maintained on a best-effort basis. No response-time guarantee, paid service tier, or commercial support agreement is implied.
